| `server/worker/director-prompt.md`, `director-script.md`, `director-quick.md` | The Director rules every backend and agent shares: shared (source, language, storyboard, notes, which rules apply), full script (template notes, script, mixed briefs, dirty steps) and quick mode (the outline, its commit and errors, dirty steps).
