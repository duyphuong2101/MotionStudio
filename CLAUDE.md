# Motion Studio

Brief-to-video tool. A director (Claude Code on a company seat) writes `source.json` and `script.json`; a deterministic engine turns them into an HTML + GSAP composition, stills, and an MP4. A person approves the storyboard in a local UI before anything is rendered.

## Commands

- `npm install` once (Node 20.12+, Chrome installed; ffmpeg comes from `ffmpeg-static`).
- `npm run ui` starts the UI on http://127.0.0.1:4780. `npm run ui:review` also prints a read-only review link (`http://<LAN IP>:4781/?code=…`) for people on the same network.
- `/studio run` (this repo's skill) processes queued briefs. `/studio status` lists jobs.
- `node engine/cli.mjs help` lists engine commands. `npm test` runs unit tests.

## Layout

- `briefs/<project>/<job>.json` input written by the UI. Changing the template or mix after a script exists moves `script.json` to `script.prev.json` and sends the job back to the Director from step 3 (source kept). An optional `voiceTake` (a .wav/.mp3/.m4a asset, one recorded take of every voice line in order) replaces TTS: prepare transcribes it locally, aligns it to the scenes (`engine/voicetake.mjs`, `config/studio.json` → `voiceTake`), cuts it per scene and keeps the script's words as captions (brand `voice.cleanup: true` runs each cut through a highpass, FFT denoise, de-esser and compressor first, `takeFilter` in `engine/voicetake.mjs`); a scene the take does not match fails prepare by name.
- `sequences/<project>/<id>.json` a sequence written by the UI: 2-12 jobs of one format (a draft may list unrendered parts; preview and render need every part done; optional `targetDuration`, and `sequenceBudget` sets each part's length against it), joined by ffmpeg (`node engine/cli.mjs sequence`) into `out/<project>/<id>/<title or id> v<N>.mp4`, a new version per render (`status.outputs.final` names the latest; older versions and a pre-version `final.mp4` stay). No model involved. A sequence id cannot be a job id in the same project. `musicBed: true` replaces the parts' own music with one brand track under the whole film (each part's `voice.wav`/`footage.wav` placed at its offset, ducked, looped by crossfade when the track is shorter).
- `profiles/<project>/brand.json`, `voice.md`, `assets/`, `icons.json`, `transcripts/<asset>.json` one folder per brand. `icons.json` holds the brand's uploaded icons as motion-kit paths (`engine/icons.mjs` turns an SVG into one M/L/C/Z path in the 100x112 box); templates get them as `icons` in the build args. Optional brand fields read by `templates/kit.mjs`: `fonts.files` (licensed font assets loaded with `@font-face`), `subtitles` (one subtitle look for every template: a preset `style` — `classic`, `highlighter`, `minimal`, `pill` (a marker pill slides from word to word) or `pop` (words pop in as spoken), a few words at a time in Roboto/Montserrat/Inter, sized for a phone, in a band clear of player controls and a portrait icon rail, which also raises `contentArea` — or a custom box, e.g. black on a white box), `logoBug` (the logo fixed top-left, `logoDark` on dark scenes), `shine` (a light band sweeps across each `.btn` once it is in), `confetti` (a burst of brand-coloured pieces flies from each `.btn` as it lands, GSAP Physics2D), `reveal` (`chars` or `lines`: headings split by GSAP SplitText, on the profiles with the plain entrance, `revealable` in `templates/kit.mjs`), `ease` (`snappy`, `soft`, `spring` or a CustomEase path from `M0,0` to `1,1`: the page's default ease `X`, `EASES` in `engine/brand.mjs`; the kit writes SplitText, CustomEase and Physics2D into a page only when its brand asks, `GSAP_FILES` in `engine/vendor.mjs` copies them into every job), `leaks` (a warm glow and one in the accent flare across the frame at every cut), `carry` (cinematic and clean only, the profiles with `carrier`: an accent bar under each scene's `[data-anchor]`, kicker or heading glides to the next scene's at every cut, `CARRY_JS` in `templates/kit.mjs`), `backdrop` (`mesh`, `aurora`, `flow` or `shapes`: a WebGL layer in the brand colours behind every scene, replacing the particles; `shapes` is lit 3D solids drifting near the frame edge) and `wipe: "liquid"` (a WebGL band in primary with accent edges sweeps across every cut, its edges smeared by their own speed; both in `templates/gl.mjs`) and `motion`, one row of `MOTION_PROFILES` in `engine/brand.mjs` that the kit, the templates and prepare read through `motionProfile(brand)` (never the name; the Brand tab lists `MOTION_OPTIONS` from `ui/shots.js`, kept in step by a test): `standard` (absent), `clean` (the cinematic layout and tight gaps with short sharp entrances, 0.15 s fades, no blur, push-in, grain or particles), `editorial` (heading words rise out of a mask, other things wipe in, a brand panel sweeps over every cut unless a brand `wipe` is set), `kinetic` (overshooting entrances, zoom and slide cuts, the standard layout, tight gaps), `parallax` (a drifting camera, text and pictures drifting at their own speed; ui-story keeps its app window still), each with one-line lit captions, and `motion: "cinematic"` (kit helpers bring things into focus word by word on an expo ease, every scene pushes in slowly, cuts are focus pulls, film grain and a vignette replace the particles (brand `film: false` drops both, for a clean frame); the explainer puts footage full-frame under a lower third; content blocks centre between the logo and the subtitles; prepare uses tight voice gaps, `config/studio.json` → `timing.tight`; cuts are blur cuts, never two scenes at once (a cut between two background colours, or to or from a full-frame picture, turns through a veil in the new scene's colour, `VEIL_JS` in `templates/kit.mjs`); captions show one balanced line at a time (`captionLines`), each word turning solid with the brand marker as it is spoken). Scenes may set `theme` (`light`/`dark`/`accent`) on the kinds that list it, and the explainer has a `flash` kind (kinetic one-item-at-a-time type, items up to 40 characters; an item flashes on the word that starts it when the voice says that word, else the beats spread over the line). Data-story `stat`, `line` and `bars` take `tone: "up" | "down"` (counted numbers green or red, a lighter green on dark), and `bars` takes `series` (two names) with `value2` on every item for two bars per row under a legend, and `layout: "columns"` for upright bars with the value above and the label below. A ui-story `shot` may set `cue` (one word of its scene's voice line): it starts 0.3 s before that word is said, shots stay at least 1.2 s apart, and pages without a cue are unchanged; a ui-story `title` may set `logo: false` to keep the brand logo off that card. A toned bars value colours its unit too. Lifestyle has a mixable `gallery` kind (2-4 `photos` as instant prints dropped in with the voice, `beats.data.gallery`); a talking-head `clip` may set `layout: split` (speaker to one half, `image` in the other) or `pip` (`image` full frame, speaker in a corner). Text marks (`engine/marks.mjs`): a template with `marks: true` in beats.json (every kit renderer) takes `[[circle:40%]]`, `[[underline:…]]`, `[[strike:…]]` or `[[mark:…]]` in `title`, `subtitle`, `text`, `tagline` or `quote` (at most 2 per field, never in a voice line; limits count the words without the brackets); the kit draws each when the voice says its first word, and the Director gets the rule as `marksRule` in its context. `voice.say` (one word as written → what the voice says, e.g. `"AMAD": "Eh Em Eh Dee"`, `".NET": "dot net"`; `spokenLine` in `engine/tts.mjs` changes only the TTS text, captions and word timing keep the script's words; the Brand tab's "Say as" box) fixes a word the voice reads wrong; check a spelling with `toPhonemes` in `engine/tts/kokoro.mjs` (a lone "A" reads as "uh"). Built-in music (`engine/library.mjs` `MUSIC`): `calm-pad`, `soft-pulse`, `steady-tech` and `bright-drive` (upbeat, major key, 120 BPM). `music.duck` (read by `engine/pipeline.mjs` `mixFilter`) dips the music under speech with `sidechaincompress` in the final mix; off by default. `sfx: { cut: "whoosh" | "hit" | "riser" | "click" | "none", gainDb: -30..0 }` (`engine/sfx.mjs`, sounds synthesised once into `library/sfx/` by `engine/library.mjs`) plays a cut sound at every scene start but the first; a scene of the templates that list `sfx` may pick its own (`none` silences that cut). Prepare writes `sfx.wav`; the final mix and a sequence music bed add it after the duck (it never dips the music); absent = no sound, and the mix is unchanged.
- `templates/<id>/beats.json` (rules the director must follow) + `template.mjs` (HTML generator). All 17 templates are built in; there is no custom-template editor. A template without `template.mjs` reuses another renderer through `extends`.
- `templates/kit.mjs` is the shared page shell (tokens, subtitles, seek contract) for the newer renderers. `beats.audio: "footage"` makes prepare cut clips into `clips/` and mix their sound as `footage.wav` (`beats.footage: "audio"` takes sound files too; `beats.levels` adds per-frame loudness). A motion scene with a `video` field gets a clip the kit seeks with the page clock (with `sound: true` the clip sets the scene length; `hold: 0-3` keeps its last frame that long after it ends); a render shows that clip (and every `clips/<clip>.mp4` `<video>`, talking-head too) as frames ffmpeg cut ahead into `frames/` (`cutClipFrames` and `CLIP_FRAMES_JS` in `engine/frames.mjs`, injected by `openComposition` at render time; the page file is never changed). Every encode is BT.709 (`BT709_VF` for screenshots and lavfi colour, `BT709_TAGS` on outputs, `engine/media.mjs`). `node engine/cli.mjs bench <project> <job>` times render Chrome counts for `render.concurrency`. The explainer's `model` kind (mixable) shows a `.glb` asset (glTF 2.0 binary, checked on upload) turning (`spin`: `turn`/`orbit`/`hero`/`reveal`/`detail`) with three.js in studio light (`env: "studio"`, a PMREM of three's `RoomEnvironment` built once per canvas; `none` for plain lamps) over a soft contact shadow on a clear ground (`shadow: false` drops it), from an optional start pose `view: { azimuth, elevation, zoom }` (ranges in `VIEW_RANGE`, the same as explainer `data.model.view`) (`templates/model3d.mjs`; prepare copies three flat into `vendor/` with `engine/vendor.mjs`; the Templates tab uses the torus from `engine/glb.mjs`). Every WebGL canvas carries `data-gl`, and `openComposition` opens such a page on SwiftShader so a render gives the same pixels on every machine; every other page opens as before. `beats.alpha` renders a ProRes 4444 `.mov` with transparency.
- `motion-kit/icons.mjs` SVG paths every template can morph between: 11 hand-drawn icons plus about 70 commerce icons generated from Phosphor (`icon-list.json` → `node motion-kit/build-icons.mjs <phosphor dir>` → `icons-set.mjs`; never edit the generated file).
- `engine/` pipeline, CLI, validation, locks. `server/` local UI server. `ui/` static UI.
- Evidence import (`engine/evidence.mjs`, `node engine/cli.mjs evidence git|csv`, the brief form's "Add evidence" panel): a person turns read-only git history of a repo listed by alias in `config/studio.json` → `evidence.repos`, or a CSV export (e.g. GA4), into fact lines that name their source. No model, no network, no credentials, the CSV is not stored, never on the review link, and not in the Director's allowlist.
- `config/studio.json` holds the caps (`director`, `director.api`, `generate`, `engine`). `config/providers.json` lists the API providers, each key in a `keyEnv` variable only; its `default` picks which of the two Director backends Run Director uses: `seat` or one provider.
- `out/<project>/<job>/` everything a job (or a sequence) produces (gitignored); prepare adds `review/sheet.jpg` (three frames per scene), `review/cuts.jpg` (eight frames close around every cut) and `review/pacing.json` (words per second, head, tail, silence, "same layout" for a third scene of one kind in a row, footage aside; the Director gets that rule as `layoutRule`; `node engine/cli.mjs review`); `notes.json` holds notes a person pins to a moment of the preview (`engine/notes.mjs`, the Preview tab, never on the review link), which the Director gets with their scene as `notes`; QA (`engine/qa.mjs`) also warns on a one-frame hard cut (ffmpeg `scdet`, `QA_RULES.cutJump`); the Shots dialog and the Director's `referenceRhythm` give an analysed video's cut rhythm (`rhythmOf` in `engine/footage.mjs`). `out/_preview/templates/<project>/<template>/` holds the Templates tab's live samples (`engine/template-preview.mjs`: each template's `beats.defaults` in the project's brand, estimated timing, a generated sample photo and clip; no voice, no render).
- `out/_footage/<project>/<asset>/` holds a video asset's shot analysis (`shots.json`, `thumbs/`, `engine/footage.mjs`, ffmpeg only); a clip cut from it in the Brand tab's Shots dialog or with `node engine/cli.mjs clip` (`--speed 0.25..4` plays it faster or slower: `setpts` plus `atempo`, the clip lasts the span over the speed; a slower clip fills the frames between with `--smooth blend` (default, `minterpolate` blend), `motion` (motion-compensated, slow to make, up to 20 s out) or `none` (repeated frames)) becomes a new asset with a `profiles/<project>/clips/<name>.clip.json` provenance sidecar.
- `out/<project>/_banner/<backdrop>-<w>x<h>.html` a hero banner (`engine/banner.mjs`): one standalone page, a WebGL backdrop from `templates/gl.mjs` (`mesh`, `aurora`, `flow`, `shapes`; default the brand's) in the brand colours on a requestAnimationFrame clock (a web page, not a render; DPR capped at 2, one still frame under reduced motion, optional pointer parallax) with an optional escaped headline (60), subline (120) and button (24), everything inline. Made by the Brand tab's "Export hero banner" (`POST /api/projects/<p>/banner`, served sandboxed from `/banner/<p>/<file>`, never on the review link) or `node engine/cli.mjs banner <project> [--backdrop] [--size 1920x600|1920x1080|1440x480|1080x1080] [--headline] [--subline] [--button] [--parallax]`. No model, no child process; `_banner` can never be a job id.
- `trash/<project>-<time>/` a project deleted from the UI: its `profiles`, `briefs`, `sequences` and `out` folders, moved rather than wiped (gitignored). A deleted sequence or job goes to `trash/<project>-<id>-<time>/` (a job only once no sequence plays it).

## Rules for using Claude here

- The seat is company-owned. Claude Code runs only when a person starts it: typed `/studio run`, or the UI's Run Director button. Run Director (`server/director.mjs`) has two backends, chosen once per click: the Claude seat (`claude.exe -p` on this machine's own login, no token read, no API key added, the allowlist in `config/studio.json` → `director`; the default) and the API worker (`server/worker/`, a tool-calling loop over one provider's HTTP API with Node `fetch` and the person's own key from the `keyEnv` variable, used only when `config/providers.json` → `default` names a provider with an adapter, a model and a key). Both run one at a time, are capped in jobs, turns, time, tokens, log size, calls and runs per day, never render or approve, pause on a usage limit or a 429, never retry, and never switch backend during a run; the seat child still receives no `keyEnv` variable. No other route may invoke Claude or a text model. The one other model path is `server/generate.mjs`: the Brand tab's Generate button makes one image (Gemini) per click (Veo clips are phase 2 of `.ai/plans/gemini-asset-worker.md`; the server refuses `kind: video` until then), and its Refresh models button lists the key's models (metadata only), with the person's own `GEMINI_API_KEY` from the environment, capped by `config/studio.json` → `generate`, saved once into the brand's assets. The Director, `engine/`, prepare, render, a cron or a loop never call it.
- The UI server binds to 127.0.0.1 and refuses other hosts and cross-site writes. Do not change that. The one network-facing piece is the read-only review link (`server/review.mjs`, user decision 2026-10-21): started by the person with `npm run ui:review`, one private IPv4, GET/HEAD only on a fixed allowlist (the normal UI with `data-review`, which hides every edit control, plus the reads it needs), a random access code per start. It never runs the Director, Generate or TTS, never shows the Director log, and has no approve, render or any write; keep it that way.
- Every director run is capped (`config/studio.json` → `director`). Every engine child process has a timeout and a capped log.
- API providers in `config/providers.json` keep keys in environment variables. The one file allowed to hold a key is the gitignored `.env` at the repo root (user decision, 2026-10-15). `server/keys.mjs` reads it once when the UI server starts, for the `keyEnv` names only, and the environment wins. Never commit, copy, zip, print or read that file any other way. The Gemini asset generator reads the person's own key (`GEMINI_API_KEY`, personal Google account, own Cloud Billing, by the user's decision of 2026-10-15); it never writes, logs or returns the key, and the seat child process and every engine child receive no `keyEnv` variable at all. The API worker reads one provider's key in-process, sends it as a request header only, and redacts every logged text; it is the second Director backend, not a second call site.
- No `--dangerously-skip-permissions`, no reuse of the CLI token.

## Conventions

- Every label, message, error and status text the tool shows (UI, server responses, CLI output, engine errors, template chrome) is English. The person may talk to Claude in Vietnamese; the product itself stays English. Video copy follows the brand's `voice.lang`, not this rule.

- Engine and server code: Node ESM, no framework, `spawn` with `shell:false` and argument arrays only.
- Every id from outside (project, job, template, file) goes through `assertId` / `assertFileName` + `within()`.
- Text into composition HTML goes through `escapeHtml`; JSON into `<script>` goes through `jsonForScript`.
- A template is deterministic: everything visible is a function of `seek(t)`. No timers, no `Math.random` at render time.

## Rules (summary — source of truth: `.ai/docs/conventions.md`)

### NEVER (security floor — never work around these; ask instead)
- NEVER invoke Claude or any model from `server/`, the UI, the engine, a cron or a loop — two person-clicked paths only, capped, one at a time, no auto-start, no retries: `server/director.mjs` (Run Director: the Claude seat with `claude.exe -p`, or the API worker in `server/worker/` on the one provider named by `config/providers.json` → `default`, with the person's own key from `keyEnv`) and `server/generate.mjs` (one Gemini image or Veo clip into the brand's assets, or one model-list call, `GEMINI_API_KEY` from the environment only)
- NEVER reuse or extract the Claude Code CLI OAuth token, or proxy/share seat access
- NEVER use `--bare`, `--dangerously-skip-permissions` or any flag that disables auth or permission checks
- NEVER bind the UI server to anything but 127.0.0.1 or relax the Host / Origin / `X-Studio` checks (sole exception: the read-only, code-gated review link in `server/review.mjs`)
- NEVER put an API key or secret in a file (env vars named by `keyEnv`; sole exception: the gitignored root `.env`, read by the server at start for the `keyEnv` names only, never committed, copied, zipped or printed)
- NEVER dump a secret file (`.env`, `*.local.md`, `*.local.json`, `*.pem`, `*.key`) with `cat`/`head`/`cp`
- NEVER commit or share a file holding a key, token or password
- NEVER `spawn` with `shell: true` or a command string
- NEVER start a child process without a timeout and a capped log
- NEVER build a path from an outside id or file name with `path.join`
- NEVER write brief, brand or script text into composition HTML unescaped
- NEVER fetch a brief URL whose host is not in the brand's `sources.allowedHosts`
- NEVER let the director run `render` or `approve`; never invent a claim in a script

### ALWAYS
- ALWAYS throw `StudioError(message, httpCode)` for expected failures; write state with `writeJson`; change job state through `setStatus`
- ALWAYS respect human locks (`humanEdit`, `mergeRespectingLocks`)
- ALWAYS run `npm test` before calling a change done; add a test for engine, lock, timing or template-contract changes
